# Project Instructions

## Build & Test

- `./gradlew assembleDebug` — debug build
- `./gradlew test` — unit tests
- `./gradlew :app:detekt` — static analysis
- `./gradlew lint` — Android lint
- `./gradlew :app:generateBaselineProfile` — generoi Baseline Profile yhdistetyllä laitteella

## Quality Tools (global, in ~/bin/)

- `lint-check` (alias `lc`) — runs ktlint + detekt + Android lint, results in `reports/`
- `security-check` (alias `sc`) — repo-local authoritative entrypoint is `tools/sc.ps1`, which delegates to the shared Android-check engine
- `security-check-full` (alias `sc-full`) — compatibility alias täydelle security-ajolle
- Don't run these scripts yourself — user runs them via `! lc` / `! sc`
- `reports/` is gitignored, never commit it
- Security risk decisions and temporary exceptions are documented in `config/security-decisions.md`
- `scripts/security-check.sh` ja muut `scripts/security-check*.sh`-polut ovat vain fail-closed-yhteensopivuusdelegaatteja samaan `tools/sc.ps1`-entrypointiin.
- `sc` ajaa yhteisen manifestin mukaiset dependency-, secret- ja Semgrep-tarkistukset. Dependency-tarkistukset voi ohittaa vain erikseen: `sc -WithoutDeps` tai `./scripts/security-check.sh --without-deps`.
- Ensimmäinen OWASP dependency-check -ajo voi olla hidas, koska se alustaa CVE-tietokannan automaattisesti. `NVD_API_KEY` nopeuttaa NVD-päivitystä, jos sellainen on käytössä.
- `sonar` ajaa projektin SonarCloud-skannauksen Gradlen `sonar`-taskilla, joka ajaa ensin `:app:jacocoDebugUnitTestReport`-tehtävän, ja kirjoittaa lokin `reports/sonar.txt`; `sonar auth login/status/...` ohjautuu edelleen SonarQube CLI:lle.
- SonarCloud-skannaus tarvitsee `SONAR_TOKEN`-ympäristömuuttujan. SonarQube CLI:n keychain-kirjautumista käytetään issueiden lukemiseen `reports/sonar-issues.json`-raporttiin.

## Conventions

- Hilt for DI, Room for local DB, DataStore for preferences
- ViewModels expose StateFlow, screens collect via collectAsStateWithLifecycle()
- All strings in `res/values/strings.xml` for localization
- No hardcoded colors/dimensions — use theme tokens (`MaterialTheme.colorScheme.*` and `MaterialTheme.knitToolsColors.*`)
- No inline `letterSpacing`, `fontSize`, or `fontWeight` overrides — use Type.kt roles. Exception: CounterScreen's main number (115sp Bold)
- Finnish in commit messages and comments

## UI Rules

- Scaffold-taustaväri: `MaterialTheme.colorScheme.background` kaikissa näytöissä, ei `surface`
- ToolScreenScaffold: puhdas teemapinta, ei ambient-kuvia
- Light+dark teema ("70s Craft Revival"), light oletuksena. `MaterialTheme.knitToolsColors` extended-tokeneille.
- Tools/Library-listat: ei ikoneita korteissa, aksenttivärinen otsikkoteksti per kohde
- Window insets: `consumeWindowInsets(scaffoldPadding)` NavHostissa — sisemmät Scaffoldit eivät lisää tuplainsetejä
- CounterViewModel scopattu `TopLevelDestination.Projects.route`-tasolle (jaettu Counter + ProjectList)
- LibraryViewModel scopattu `TopLevelDestination.Library.route`-tasolle (jaettu Library + alanäytöt)
- Navigaatio: 5 tabia (Projects, Library, Tools, Insights, Settings). Sovellus käynnistyy Projects-tabista. Room v23.
- Projects-kansiot ovat kevyt paikallinen järjestely: kompakti valitsin avaa vieritettävän sheetin, jossa All Projects ja Unfiled ovat virtuaalinäkymiä. Älä lisää kansiokortteja, kansiotabeja tai projektirivien pysyviä siirtonappeja. Kortittomat projektirivit ja suodatettu Continue-hero säilyvät; aktiiviset ja valmistuneet rivit voivat olla samassa joukkovalinnassa. Yksittäinen Move to folder kuuluu Counterin nykyisiin projektiaktioihin, eikä kansiosiirto aloita tai päätä työskentelyistuntoa. Kansioiden järjestely on ilmainen; projektinluonnin nykyinen Pro-raja säilyy.
- Projektin luettavien PDF-tiedostojen, ensisijaisuuden, järjestyksen ja dokumenttikohtaisen lukutilan auktoriteetti on `project_documents` ja `ProjectDocumentRepository`; `counter_projects`-taulun vanhat pattern- ja lukutilakentät ovat vain migraatioyhteensopivuutta, eivät rinnakkainen lähdetotuus.
- Destruktiivinen repository-polku kerää siivoustiedot ennen transaktiota, kommitoi auktoritatiivisen tietokantapoiston ensin ja siivoaa app-owned-tiedostot vasta sen jälkeen best effort -periaatteella. Tietokantavirhe tai kommittia edeltävä peruutus säilyttää tiedostot; kommitin jälkeinen tiedostovirhe saa jättää orvon mutta ei saa esittää tietokantapoistoa peruttuna. Jaetut PDF:t kulkevat aina `SavedPatternRepository.deleteLocalPatternFileIfUnused`-portin kautta.
- Työskentelyistunto alkaa vain projektiaktioiden Start-toiminnosta. Stop avaa yhteenvedon, jossa istunto tallennetaan, hylätään tai jätetään aktiiviseksi. Projektin avaaminen, vaihtaminen, historia, taustalle siirtyminen tai ViewModelin poistuminen ei käynnistä, jaa eikä päätä aikaa. Aktiivinen tila näkyy projektirivillä ja counter-heron lähellä kompaktina tekstirivinä ilman reunusta, gradienttia, hehkua tai väriraitaa. Epävarma väli pyydetään kerran omassa dialogissa: Add hyväksyy ehdotuksen ja jatkaa, Discard jättää epävarman välin pois ja päättää, Edit tallentaa käyttäjän antaman kokonaisajan ja päättää. Dialogin sulkeminen jättää asian ratkaistavaksi passiivisesta tilarivistä.
- Voice- ja mikrofonikomennot puuttuvat tarkoituksella. Älä palauta `SpeechRecognizer`-, `TextToSpeech`- tai keskustelevaa voice-flow'ta ilman uutta nimenomaista tuote- ja turvallisuuspäätöstä.
- Multi-select UI: `SelectionIndicator` ja `SelectModeDeleteBar` jaetut internal composablet `SavedPatternsScreen.kt`:ssä
- Insights: editoriaalinen typografianäyttö ilman kortteja — vain hiusviivat (`InsightsDimens.RuleStrongAlpha` / `RuleHairlineAlpha`). App barin otsikko on **valittu aikaväli** (`InsightsRangeTitle`, `headlineMedium` + valikko), ei näytön nimi: alanavigaatio kertoo jo missä ollaan. Älä palauta erillistä aikavälivalitsinriviä — otsikkorivi, segmenttivalitsin ja projektipilleri söivät yhdessä 188 dp ennen kuin yhtään dataa näkyi, ja kaavio jäi ruudun alle. Projektisuodatin on täytetty `surfaceVariant`-pilleri rivin oikeassa reunassa — myös yksin ollessaan, koska vasemmalla se luki toisena otsikkona. Sen visuaalinen korkeus alittaa kosketuskohteen minimin tarkoituksella; osumakohde tulee `minimumInteractiveComponentSize()`-laajennuksesta. **Molemmat** pudotusvalikot (aikaväli ja projekti) käyttävät samaa `InsightsMenuItem`-riviä: sovelluksen oma pinta ja muoto, valinta merkitty lihavoinnilla ja checkillä, projektiriveillä lankaväripisteet. Teksti on `bodyMedium` — isommalla koolla check söi leveyttä juuri valitulta riviltä. `SessionHistoryScreen` näyttää projektin nimen osiomerkkinä, koska Insights on sen toinen sisäänkäynti eikä pelkkä "History" kerro kenen istuntoja katsotaan. Vaakapehmuste 16 dp. Osio-otsikot ovat Libraryn tyyliset pienet versaalit `brandWine`-värillä, eivät omat otsikkokokonsa — heron alla saa olla vain yksi äänekkäät taso. Järjestys: aikavälivalitsin → projektisuodatin → aikavälirivi (kicker) → hero → tilastot → trendirivi → "Every day" (pylväskaavio) → "Where the time went" (yksi lankapalkki + projektirivit). Osuudet luetaan **yhdestä** `InsightsProjectMixBar`-palkista; älä palauta rivikohtaisia osuuspalkkeja tai prosentteja — viittä erillistä palkkia ei voi verrata keskenään. Kaaviossa ei ole maksimileimaa (korkein pylväs on asteikko) eikä pysyvää käyttövihjettä, eikä listan alla kannustuslausetta. All Time ryhmittelee kolmella tasolla: alle kuukausi päiviin, alle `ALL_TIME_WEEK_BUCKET_MONTHS` viikkoihin, sen yli kuukausiin — kaksi kuukausipylvästä ei ole kaavio. Plotin korkeus seuraa ämpärimäärää (`chartPlotHeight`), "today"-leiman varaus on nolla lyhyillä väleillä (`todayLabelClearance`), ja trendirivi vaikenee kun edellinen jakso jää alle `TREND_MINIMUM_BASE_MINUTES`-rajan. Tilastosarake jätetään pois kun sillä ei ole kerrottavaa (ei rivejä, tai putki 0–1), ja sarakkeet ladotaan vasemmalta kiinteällä välillä — painotettuina kaksi jäljelle jäänyttä hakeutuivat vastakkaisiin reunoihin ja väliin jäi kolo. Plotin korkeus katsoo **aktiivisten** ämpärien määrää eikä akselin pituutta. Yhdelle projektille suodatettuna "Where the time went" jätetään kokonaan pois: suodatinpilleri, yksivärinen 100 %:n palkki ja yksi rivi olivat sama tieto kolmesti — tilalle jää `InsightsLastWorkedNote` ja `HubListItem`-linkki projektin omaan `SessionHistoryScreen`iin. **Älä piirrä istuntolistaa Insightsiin** — se näyttö on jo olemassa, ja oma kopio olisi samaa toistoa jota tästä näytöstä on purettu. Linkki näkyy aina kun projekti on valittuna, myös ilman istuntoja tällä aikavälillä. `session_history/{projectId}` on rekisteröity myös Insights-graafiin, jottei alanavigaation korostus hyppää Projectsiin. Kaavio jätetään pois kun dataa on alle `MINIMUM_CHART_BARS` ämpärissä: ainoa pylväs piirtyisi aina täyskorkeana. Aikavälirivi (kicker) näytetään **vain All Timessa**: viikko- ja kuukausinäkymässä otsikko sanoo jo aikavälin ja kaavion akseli näyttää samat päivät. Älä laita riville painotettua Spaceria — kaksi `weight(1f)`-lasta jakavat vapaan tilan tasan ja teksti katkeaa 100 dp tyhjän vieressä. Tilastorivi jää kokonaan pois kun yksikään sarake ei yllä kertomaan mitään; nollasarake on kohinaa. Pylväissä on sileneuleen silmukkapinta (`knitStitchMetrics` / `knitStitchLattice`): yksi Path leikataan jokaisen pylvään siluettiin, varjon alfa pidetään matalana jottei pylväs putoa alle 3:1, ja alle `ChartStitchMinBarHeight`-korkuiset pylväät jäävät sileäksi. Kaavion valinta on merkkiviiva perusviivassa. Älä palauta valintakaistaa, pystyapuviivaa (se työntyi pylvään yläpuolelle ja luki tuntosarvena) äläkä pylväiden himmentämistä — kaista luki harvassa datassa renderöintivirheenä, ja himmennys pudotti pylväät alle graafisten elementtien 3:1 kontrastin (3,3:1 täydellä peitolla ei voi vaimentua yli kolmeen millään alfalla). Osio jätetään kokonaan pois kun aikavälillä ei ole minuutteja, ja otsikko seuraa ämpäriväliä (`insights_section_month_by_month`). Akselilla "today" varaa `TODAY_LABEL_CLEARANCE`-solut eikä harva akseli pinnaa leimoja reunoihin (`SPARSE_AXIS_MAX_BUCKETS`). Putkisarake näyttää parhaan putken kun nykyinen on nolla (`streakStatDisplay`), eikä trendirivi toista sitä (`allTimeBestStreakTrend`). Aikaväliä **ei koskaan interpoloida hero-lauseeseen**: se on oma sijamuodoton rivinsä (`insights_range_open_format`), koska taivutuskielissä muotoiltu päivämäärä ei voi olla lauseen sisällä. Hero on pelkkä luku ja itsenäinen substantiivilauseke ("5 projects"), ei lauseen puolikkaita: johdantolause poistettiin, joten `insights_hero_trailing_projects` **ei saa olla lauseen jatke** — taivutuskielissä "5 projektiin." jäi ilman verbiä. Kaavion lukema näkyy osio-otsikon mittalukurivillä vasta kosketuksen jälkeen (`chartHeaderMeta`, live region siinä rivissä), ei omalla pysyvällä rivillään. Kestot aina tunteina ja minuutteina `DurationDisplayFormatter` + `ui/components/DurationText`-polun kautta — myös `SessionItem`issa ja `ProjectListScreen`issa, joilla oli omat apurinsa (suomeksi "36m" alle tunnin ja "1t 5min" yli tunnin, samassa listassa). Tahti on min/rivi (`MinutesPerRowFormatter`). Kaavion valinta liikkuu napautuksella, vaakavedolla ja ruudunlukijan custom actioneilla; nykyinen piirto näyttää valinnan vain perusviivan merkkinä ilman valintakaistaa, pystyapuviivaa, pylväiden himmennystä tai maksimileimaa. Projektien värit `yarnColorForId(projectId, MaterialTheme.knitToolsColors.yarnPalette)`-apurista — paletti on teemakohtainen (`YarnColors` / `LightYarnColors`), koska kermataustalla vaaleat langat jäivät 1,86–2,67:1 kontrastiin; `YarnPaletteContrastTest` lukitsee 3:1 rajan, rivit avaavat projektin `CounterLaunchRequest`-mekanismilla. Omat mitat `ui/theme/InsightsDimens`-tokeneissa.
- Pro: käyttäjä aloittaa 14 päivän kokeilun itse. Olemassa oleva sisältö pysyy käytettävissä oikeuden päätyttyä; portit koskevat vain uusia Pro-objekteja ja edistyneitä esitystapoja. Kontekstikehote säilyttää odottavan toiminnon, eikä navigoi hiljaa yleiselle ostosivulle. Insights laskee `hasMeaningfulChartData`-arvon luovuttamatta kaaviopisteitä ilmaiselle UI:lle ja näyttää Pro-kehotteen vain vähintään kahdella ei-tyhjällä korilla. Kehote on muun Insightsin tavoin kortiton editoriaalinen sisältö hiusviivojen välissä.
- Notes: bottom sheet + full-screen editor (`notes_editor/{projectId}`), `NotesEditorViewModel` ja paikallinen auto-save. Project note replacement kulkee `CounterRepository.saveProjectNotes`-polun kautta, jotta rinnakkaiset editorivirrat eivät ylikirjoita toisiaan.
- Notes editing is local-only; älä palauta cloud-journalia, AI-siistintää tai voice-transcript-journalointia ilman uutta nimenomaista päätöstä.
- Ravelry API: vanha backenditön päätös on superseded. Ravelry-secretit, token exchange ja tokenit eivät elä Androidissa; Android käyttää Firebase Auth + Cloud Functions -backend-rajaa `RavelryBackendClient`in kautta. `RavelryAuthManager` omistaa backend-auth-tilan, start/status/disconnect-kutsut ja token-free `knittools://ravelry-auth-complete` callbackin; auth avataan Auth Tabilla ja Custom Tabs jää fallbackiksi. URL/share-import ja saved-pattern UX ovat paikallisessa lähteessä. Saved patterns säilyttävät Room v23:ssa schema 19:ssä käyttöön otetun kanonisen `free`/`paid`/`unknown`-saatavuuden; etäkuvat käyttävät yhtä HTTPS-rajattua Coil-verkkopolkua ja poistuvat hiljaisesti asettelusta latausvirheessä. Todellista Firebase/Ravelry-käyttöönottoa tai päästä päähän -ajoa ei pidä päätellä paikallisista testeistä.

## Google Play

- SplashScreen: `installSplashScreen()` ennen `super.onCreate()`; yksi kiinteä brändisplash tulee `values/themes.xml`-tiedostosta ilman järjestelmän light/dark-resurssihaaraa, ja varsinainen sovellusteema ratkaistaan `PreferencesManager.preferences`-arvosta ennen splashin poistamista
- In-App Review: triggerit Pro-osto tai 20+ laskuritoimintoa, pyydetään kerran (DataStore)
- In-App Updates: flexible mode, checkForUpdate (onCreate), checkDownloadedOnResume (onResume)
- Baseline Profiles: `:baselineprofile`-moduuli, generoi `./gradlew :app:generateBaselineProfile`
