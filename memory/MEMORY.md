## 2026-05-08

- 2026-05-10: Widget counter -launchit kovennettiin intent-spoofingia vastaan. `MainActivity.createCounterLaunchIntent()` rekisteröi launch-id:n `data/storage/CounterLaunchTokenStore`en, `MainActivity` hyväksyy counter-extra-reitityksen vain tunnetulla id:llä, ja OAuth-callback-intentit eivät saa käynnistää counter-navigointia vaikka mukana olisi counter-extra-arvoja.
- 2026-05-15: Ravelry-autentikointi pidettiin tietoisesti backendittömänä. OAuth-valtuutus lähettää PKCE-parametrit, mutta token exchange käyttää edelleen client secretiä ja API fallback käyttää Basic Authia, koska Ravelrylle ei tule backendia. Release build vaatii `KNITTOOLS_ALLOW_EMBEDDED_RAVELRY_SECRETS=true` ja riskipäätös on dokumentoitu `config/security-decisions.md`:ssä.
- 2026-05-09: Widgetistä avattu counter käyttää nyt kertakäyttöistä `CounterLaunchRequest.requestId`-tunnistetta. `MainActivity` tallentaa käsitellyn tunnisteen `savedInstanceState`en, tyhjentää intent-extrat kuittauksen jälkeen ja hyväksyy `onNewIntent`-polun uutena käyttäjän käynnistyksenä.
- 2026-05-09: Debug-only Ravelry credentialit kuuluvat ignored `debug.credentials.properties` -tiedostoon, eivät `local.properties`-tiedostoon.
- 2026-05-09: Vanhat relocation-kopiot poistettiin: `ui/screens/pattern/PdfPageRenderer.kt`. Canonical-toteutus on `data/storage/PdfPageRenderer.kt`.
- 2026-05-12: IO-dispatcher keskitettiin Hiltin `di/DispatchersModule`-moduuliin (`@IoDispatcher`). Repositoryt ja ViewModelit injektoivat IO-dispatcherin sen sijaan, että ne käyttäisivät suoraan `Dispatchers.IO`:ta.
- 2026-05-12: Monivaiheiset Room-kirjoitukset keskitettiin repositoryihin `data/local/DatabaseTransactionRunner`in kautta. Yarn/project-linkitykset kulkevat `YarnCardRepository`n kautta: `saveCard` normalisoi tallennettavan `linkedProjectId`-arvon ja `updateLinkedProjectId` päivittää eksplisiittiset relinkit sekä `yarn_cards.linkedProjectId`-kenttään että projektien `yarnCardIds`-listoihin yhdessä. Pattern attach/detach kulkee `CounterRepository.attachPattern` / `detachPattern` -metodien kautta, jotta saved pattern -rivi, annotaatiot ja projektin pattern-kentät pysyvät atomisina.
